# dsh-workspace-cake

左侧「工作区」这一块的全部能力，一个包搞定：右键快捷入口、置顶与排序、运行/未读状态标记、标题栏的折叠按钮。

所有开关都在 **设置 → 工作区Cake** 里（设置页左侧列表的名字就叫这个），改完即时生效，保存在浏览器本地。

## 一、工作区右键菜单

右键和行尾「⋯」是同一个共享菜单，六个入口：

| 顺序 | 菜单项 | 行为 |
|--:|:--|:--|
| 90 | 置顶 / 取消置顶 | 把该工作区钉到列表最上面；纯本地偏好，不碰工作区和会话 |
| 103 | 打开文件树 | 切该工作区上屏，侧边栏开 `files` 页（装了 better-sidebar 就是它接管的那棵） |
| 105 | 打开终端 | 切上屏后开终端，默认 better-sidebar 底部工作台 |
| 107 | 复制绝对路径 | 写剪贴板并弹「已复制路径」 |
| 109 | 在 Cursor 中打开 | 走宿主 `open-in-app` 应用目录 |
| 111 | 在 VS Code 中打开 | 同上 |

内置的「重命名」是 100、「在 Finder 中显示」200、「删除」300，本插件不碰它们。

每一条都能在设置里单独关掉；关掉后菜单里就不出现那一行。

## 二、置顶

- 置顶的工作区永远排在最前，**置顶之间也按最近更新排序**——谁刚有过对话谁靠上。
- 其余分组按最近更新排在置顶块后面。
- 置顶集合存在浏览器本地 `dsh-workspace-cake.pinned.v1`，刷新、重启都在。
- 工作区被删除后，它的 id 会在下一次对齐工作区快照时自动清掉，不会永远留着。
- **顺序被投影接管时拖动不生效**：最近更新排序下你拖一个工作区，宿主要写的是屏幕上看不见的顺序，所以拖动提交被拦下并提示「切到手动排序再拖」。
- 置顶块与其余分组之间有一条浅灰细线，取宿主的 `--dsw-alias-border-l1`，明暗主题自动跟随；颜色由 `DIVIDER_COLOR` 常量控制，设成 `transparent` 就没有线。

## 三、三个状态：呼吸、染色、竖条

| 状态 | 依据 | 表现 |
|:--|:--|:--|
| 正在输出 | 会话 `running === true` | 名字染上蓝紫**并呼吸**（不透明度 60%↔100%，周期 2.8 秒）；系统开「减少动态效果」时只染色不动 |
| 输出完但没看 | 会话状态 `completionUnread === true` | 名字**静止**染着蓝紫（不呼吸），行左侧多一条 3px 静态暖色竖条 |
| 看过了 | 两者都为 false | 染色与竖条一起消失 |

- 染色色值：亮色主题 `#3f51a8`、暗色主题 `#93a4f5`（靛蓝偏紫），用 `light-dark()` 跟着宿主的 `color-scheme` 切换。想换成截图里那种天蓝就改成 `light-dark(#2f6f9e, #74a6d0)`。
- 同一工作区里若一个会话在跑、另一个有未读，两个标记可以同时出现，互不遮挡：竖条走行左缘的 `::after`，置顶分隔线走 `::before`。
- 未读只认宿主确认的 `completionUnread`；等你审批 / 提问走的是 `pendingInteraction`，不算未读（那一行自己已有提示）。
- 跑完但出错的未读（`completionFailed`）竖条换成错误色，跟正常未读分开。
- 行标记只观察侧栏的滚动容器（`[data-sidebar-scrollport]`），不盯整页——聊天区刷屏不会带来无谓开销；容器在收窄/展开时重挂，插件每秒比对一次身份自动跟上。
- 结构自检：宿主若改了行的内部结构，控制台会提示一次「名字染色/呼吸可能不生效」，而不是静默失效。

## 四、最近更新排序

- 分组顺序按「该工作区最近一次真实对话的时间」排列，有新对话的工作区自动上浮。
- 跳过新建会话占位（`blank`）和子代理派生的会话（`origin: 'subagent'`）；归档会话仍然算一次真实对话。
- 没有已加载对话的工作区落到最后；时间相同保持宿主原相对顺序，结果稳定不跳。
- 只在「分组方式 = 按工作区」时生效；「手动排序 / 按工作区树 / 单列表」保持宿主行为。
- **不写宿主状态**：不移动、不归档任何会话，不改宿主的持久化工作区顺序。

## 设置页

**设置 → 工作区Cake**，四组开关，默认全开：

| 分组 | 开关 |
|:--|:--|
| 工作区可视化效果 | 呼吸动效 / 未读提醒-静态染色 / 未读提醒-左侧竖线 |
| 工作区右键菜单 | 置顶功能 / 打开文件树 / 打开终端 / 复制绝对路径 / 在 Cursor 中打开 / 在 VS Code 中打开 |
| 工作区位置排序 | 最新发言的工作区自动上浮 |
| 工作区折叠按钮 | 折叠工作区专用按钮 |

- 视觉开关切换走 `<html>` 上的数据属性，CSS 直接按属性生效，不需要重建样式，也不用刷新。
- 「置顶功能」是总开关：关掉后右键里的置顶入口隐藏，已置顶的工作区也暂不参与排序；置顶集合仍留在本地，重新打开立刻恢复。取消置顶就在每一项自己的右键里，不另设「取消全部」。
- 设置存在浏览器本地 `dsh-workspace-cake.settings.v1`，跟置顶集合一样，换浏览器不共享。

## 调参

`client.js` 顶部「可调参数」：

- `MENU_ORDER`：六个菜单项的顺序。
- `RECENT_ORDER`：设 `false` 就只保留置顶分区，其余分组回到宿主自己的顺序。
- `TERMINAL_TARGET`：`'bottom'`（默认）或 `'right'`。
- `PIN_STORAGE_KEY`：置顶集合的 localStorage 键。
- `DIVIDER_COLOR`：分隔线颜色，默认宿主浅灰边框色；想要更淡可套 `color-mix(... , transparent)`，不想要线就写 `transparent`。
- `NAVIGATION_TIMEOUT_MS` / `OPEN_ATTEMPTS` / `OPEN_RETRY_DELAY_MS` / `MARK_DELAY_MS`：各种等待窗口。

## 失败时

菜单执行会丢掉错误对象，所以插件自己 `console.error` 一行（前缀 `[dsh-workspace-cake]`），菜单里显示「操作失败，详情已写入控制台」。

## 改完怎么生效

`client.js` 是手写 ESM，没有构建步骤。改完保存 → 刷新页面（Cmd+R）。改了 `package.json` / `cordis.patch.yml` 或新增文件，需要在 DSH 里让 profile 重新组合一次（Plugins 页拨一次开关，或让 agent 调 `set_plugin`）。

## 结构

```
dsh-workspace-cake/
  package.json         bundle 清单
  cordis.patch.yml     插入一行插件
  index.js             Host 半边：无逻辑
  client.js            全部逻辑：菜单、置顶、排序投影、状态标记、设置页、折叠按钮
  LICENSE              MIT
  CHANGELOG.md         版本记录
  locale/{zh,en}.json  Plugins 页面的标题与说明
  icon.svg             图标
```
